# Blog

このリポジトリはシンプルな静的ブログのサンプルです。

- 構成:

  - `index.html` - メインの HTML ファイル
  - `posts.js` - 記事データ（JSON 風）
  - `js/script.js` - クライアントサイドのスクリプト
  - `css/style.css` - スタイルシート

- 動作方法:
  1. ローカルでファイルを開く: ブラウザで `index.html` を直接開いてください。
  2. 必要に応じてローカルサーバーを利用する場合（推奨）:

````bash
# 簡易サーバー例 (Python 3)
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
# OmuOmu-blog

シンプルな静的ブログのサンプルサイトです。HTML/CSS/JavaScript の最小構成で構築されており、ローカルで編集・公開して学習・運用できます。

**プロジェクトの目的**
- 個人用の軽量な静的ブログの雛形
- HTML/CSS/JS を学ぶためのサンプル

**主なファイル構成**
- `index.html` : トップページ（一覧、導入）
- `article.html` : 記事テンプレート（個別記事ページ）
- `css/style.css` : サイト全体のスタイル
- `js/script.js` : クライアントサイドの挙動（必要に応じて編集）
- `LICENSE` : ライセンス（MIT）

**動作確認 / ローカルでのプレビュー**
- ブラウザで直接開く: ファイルをダブルクリックして `index.html` を開く
- 推奨: 簡易ローカルサーバーで確認（相対パスやフェッチ動作が安定します）

```bash
# Python 3 の簡易サーバーを使う
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く

# Node.js の http-server を使う場合（事前にインストール）
npx http-server -p 8000
````

**記事の追加・編集**

- 手軽に追加する場合は `article.html` をコピーして `article-<slug>.html` のように作成し、`index.html` にリンクを追加してください。
- デザインを変更する場合は `css/style.css` を編集します。
- 動的な挙動を追加する場合は `js/script.js` を編集してください。

**貢献・問い合わせ**

- 小さな修正やデザイン提案はプルリクエストで歓迎します。
- バグ報告や機能要望は issue を作成してください。
